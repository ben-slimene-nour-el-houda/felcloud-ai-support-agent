# Felcloud AI Support Agent: Knowledge Sources Inventory (Day 1)

This document outlines the knowledge sources that will be ingested into Qdrant to power the RAG pipeline for the Felcloud AI Support Chatbot.

## 1. Documentation
- **OpenStack User Guides**: Official documentation and Felcloud-specific guides for users managing instances, networks, and storage.
- **Felcloud API Documentation**: Endpoints, schemas, and usage examples for automating infrastructure.

## 2. FAQs
- **Troubleshooting FAQs**: Common issues related to VM connectivity, volume attachment, and authentication.
- **Billing & Account FAQs**: Information on quotas, billing cycles, and account management.

## 3. Anonymized Support Tickets
- **Resolved Incident Reports**: Past incidents that have been successfully resolved, stripped of PII.
- **Configuration Examples**: Working examples of complex network configurations (e.g., LBaaS, VPNs) extracted from past support interactions.

## 4. System Architectures
- **Standard Deployment Patterns**: Documentation on recommended architectures for deploying on Felcloud.
